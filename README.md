# 로컬 음성 비서 (Local Phone Agent 1.0.2)

휴대폰 안의 작은 로컬 AI(기본: 카카오 Kanana 1.5 2.1B, Adreno GPU)가 음성 명령을 처리합니다.
**전체 명령 목표를 유지하고, 공식 API로 해결할 수 없으면 실제 앱 화면을 읽으며 작업을 이어갑니다.**
장소·앱별 설정·기억한 방법은 선택적인 빠른 경로입니다. 그 경로가 **전체 요청**을 처리할 때만 사용합니다.
조건 추가, 비교, 기존 상태 유지, 변경, 여러 단계가 필요한 요청은 원문 전체를 공통 화면 AI에 전달합니다.
앱의 기능마다 명령어나 실행 함수를 등록하는 구조가 아닙니다. AI가 현재 화면에서 메뉴·검색·버튼·상태·실제 값을 읽고 다음 동작을 정합니다.
단순 길안내 시작에는 목적지와 실제 안내 시작을 확인하는 별도 검증기가 있습니다. 다른 목표를 단순 길안내 시작으로 축소하지 않습니다.

```
단축키 → 음성 인식(기기 내장) → 명령
  ├─ 앱 실행·지원하는 설정 화면 → Android API로 열고 실제 화면 확인
  ├─ 등록된 장소 + 길안내 말    → 네이버 지도 링크 → 목적지·안내 화면 검증
  ├─ 미등록 목적지 길안내       → 지도 열기 → 저장 장소·길찾기·검색 UI에서 해결
  ├─ 음악 재생/정지/다음 곡      → 미디어 버튼 신호
  └─ 조건/복합 요청·그 밖의 일     → 전체 목표를 유지하는 공통 화면 AI
        관찰 → 동작 선택 → 실행 → 실제 변화 확인 → 필요하면 재계획 → 전체 목표 검증
        탐색 수단: 앱 열기, 클릭, 길게 누르기, 입력, 사방 스크롤, 상세 관찰, 뒤로가기
```

## 구성

| 부분 | 파일 | 역할 |
|---|---|---|
| 도구 우선 진입점 | `core/.../Tools.kt` | 명령 분류(Router), 장소 저장(PlaceBook), Assistant |
| 화면 조작 루프 | `core/.../Agent.kt` | 관찰 → 판단 → 실행 → 검증, 보호 동작 차단(Guard) |
| 행동 재확인 | `core/.../ActionGrounding.kt` | 계산 뒤 같은 실제 버튼을 찾아 ID 재연결, 대상 변경 거절 |
| 전체 목표 보존 | `core/.../GoalScope.kt` | 복합 요청의 단일 Tool 축소 방지, 완료 체크리스트 |
| 빠른 경로의 범위 | `core/.../ShortcutGoals.kt` | 요청 전체가 단순 작업에 해당할 때만 최적화 허용 |
| 하네스 규칙 | `core/.../Harness.kt` | 작은 모델이 자주 틀리는 판단을 AI 없이 처리 (아래 표) |
| 결과 확인 | `core/.../CompletionGrounding.kt`, `StateMutation.kt`, `UiProofs.kt` | 실제 관찰·변경 근거만 참조하고 전체 목표 검증, 실제 선택과 요청 값 충돌 검사 |
| 작업 중 관찰 기억 | `core/.../ObservedFacts.kt` | 후보의 거리·시간·적용 상태를 유지하고 과거 값과 현재 상태 구별 |
| 명령 해석 보조 | `core/.../GoalText.kt` | 목표 단어, 검색어, 한/영 용어, 관련 메모 고르기, 짧은 결과 문장 |
| 화면 요약 | `core/.../Screen.kt` | 접근성 트리 → 번호 목록, 목표 단어 ★ 표시 |
| 출력 강제 | `core/.../Grammar.kt` | 화면에 있는 번호와 정해진 동작만 생성 |
| 경로 기억 | `core/.../Recipes.kt` | 사용자가 [기억하기]로 확인한 경로만 다음에 재실행 |
| 화면 조작 | `app/.../access/` | 접근성 서비스, 앱 실행(새로 시작), 네이버 지도 링크, 주소→좌표 |
| 로컬 AI | `app/.../llm/`, `app/src/main/cpp` | llama.cpp + OpenCL(Adreno), 모델별 대화 형식 |

### 빠른 경로와 공통 실행 규칙

| 상황 | 처리 |
|---|---|
| 뜻 없는 말("켰어", "고마워") | 아무것도 하지 않음 |
| 잠금/인증 화면 (보안 폴더 패턴 등) | 음성으로 잠금 해제 요청 후 대기, 절대 입력하지 않음 |
| 화면 전환 중(읽을 요소 없음) | 기다림 |
| 단순 작업 중 재개 창·하단 패널 | 단순 요청의 범위에서만 자동 처리. 일반 목표는 AI가 판단 |
| 단일 "X에서 Y 검색해줘" | 검색 제출을 빠르게 처리한 뒤 전체 목표 검증. 조건이 있는 '찾아줘'는 일반 AI가 탐색·비교 |
| "X 화면 열어줘" | X로 시작하는 항목이 하나뿐이면 열기(스위치는 누르지 않음) |
| 단순 길안내의 목적지 선택 직후 | 안내 시작과 실제 안내 화면을 검증 |
| 일반 요청의 동작·완료 | AI가 다음 행동과 예상 결과를 정함. 예상은 증거로 쓰지 않으며 실행 후 관찰로 검증 |
| 스위치·선택 상태 변경 직후 | 전체 목표를 검증하여 이미 적용한 상태를 다시 누르는 반복 방지 |
| 완료 선언 | 전체 목표·대상·조건을 별도 검증. 사용할 수 있는 버튼만으로 완료하지 않음 |
| 이른 질문·실패 선언 | 현재 화면과 이력으로 자동 해결 경로를 한 번 더 검토 |
| 상세 관찰 | 현재 실제 트리를 목표 관련 내용 중심으로 다시 요약. 새 정보 없는 반복은 제한 |
| 목록 끝이라 스크롤 무반응 | 반대 방향 스크롤 |
| 결제·송금·비밀번호·권한 허용, 요청 없는 삭제, 출발지/도착지 전환 | 누르지 않음 |
| 명령에 적힌 앱이 있을 때 다른 앱 | 명령 전체에 명시된 추가 앱으로 이어지는 작업은 허용 |
| AI 계산 중 다른 앱이 전면에 나타남 | 이전 명령으로 새 앱을 조작하지 않고 중단 |
| 버튼은 그대로이고 거리·시간·다른 행만 바뀜 | 같은 실제 버튼을 다시 확인해 실행, 화면 전체 재계산을 반복하지 않음 |
| 비활성 버튼·효과 없던 동일 동작 | 출력 문법과 실행 단계에서 제외 |

**AI 메모**(설정 화면)는 코드가 아닌 힌트입니다. `[키워드, …]`를 앞에 붙이면 그 단어가 명령에 있을 때만 쓰입니다.

## 개발과 시험 (USB 디버깅)

```powershell
.\scripts\dev.ps1 install                     # 빌드 후 설치 (앱을 강제 종료하지 않음: 접근성이 꺼짐)
.\scripts\dev.ps1 push-model [file.gguf]       # 모델을 휴대폰으로 복사
.\scripts\dev.ps1 run "설정에서 배터리 화면 열어줘"
.\scripts\dev.ps1 eval kanana-1.5-2.1b-instruct-Q4_K_M.gguf   # 앱 안 판단 평가 (다른 앱 조작 없음)
.\scripts\live-suite.ps1                      # 되돌릴 필요 없는 실기 명령 14개
.\scripts\live-suite.ps1 -New                 # 튜닝에 쓰지 않은 명령 10개 (일반화 확인)
.\scripts\dev.ps1 traces                      # 단계 기록(JSONL) 가져오기
```

휴대폰에서 한 번만 할 일:
1. 설정 → 접근성 → 설치된 앱 → **음성 비서 화면 조작** 켜기
2. 설정 → 애플리케이션 → 음성 비서 → 배터리 → **제한 없음** (잠자는 앱으로 강제 종료되면 접근성이 꺼짐)
3. 측면 버튼 두 번 누르기 등을 **음성 비서** 앱 열기로 지정
4. **장소 등록은 선택**입니다. 등록하면 링크로 먼저 시도하고, 등록하지 않으면 지도 화면에서 찾습니다.

## 업데이트

**음성 비서 설정 → GitHub 업데이트 확인**을 누르면 공개 릴리즈의 새 APK를 자동 다운로드합니다.
크기·SHA-256·실제 패키지·버전·설치를 지원하는 Android 버전·현재 앱과 같은 서명을 확인한 뒤
Android 설치 화면을 엽니다. 처음에는 이 앱의 '이 출처 허용'이 필요하며 최종 설치는 Android에서 확인합니다.
모델 파일과 선택, 메모 및 장소는 앱 업데이트로 유지됩니다.

배포 계약은 `update-agent.json`(channel=`agent-v1`)과 `LocalPhoneAgent.apk`입니다.
1.0 계열은 클로드 수정본의 서명을 사용합니다. 0.7 계열 APK와 서명이 다르므로 직접 덮어쓰는 업데이트는 불가능합니다.
배포 APK를 재빌드할 때는 **같은 로컬 키**를 `LPA_SIGNING_STORE`로 지정합니다. 키는 저장소에 넣지 않습니다.

## 완료 확인과 진단

실기 결과와 원인별 설명은 [1.0.1 공통 실행·내비 진단 보고서](docs/navigation-diagnosis-1.0.1.md)에 있습니다.
범용 목표 처리 구조와 1.0.2의 검증 범위는 [범용 에이전트 개선 보고서](docs/general-agent-1.0.2.md)에 있습니다.

내비는 경로 미리보기의 '도착 예정'이나 버튼 클릭 전달만으로 완료하지 않습니다.
목적지 선택 이력과 실제 안내 시작 증거가 함께 있어야 완료합니다. 링크 확인 실패는 화면 작업으로 이어집니다.
성공한 방법을 기억할지는 설정의 **기억한 방법**에서 선택합니다. 완료 후 20초 동안 질문을 기다리지 않습니다.

실행 기록은 휴대폰의 `Android/data/dev.localphone.agent/files/traces/`에만 저장됩니다.
음성·텍스트 호출 출처, 원본 ASR 후보와 confidence, 모델·GPU 설정, 분류 원문, 화면과 동작,
내비 검증 상태, 실행 시간(음성 인식 완료 후 목표 10초), 취소와 종료를 기록합니다.
파일에는 개인 화면 정보가 들어갈 수 있으므로 저장소 및 릴리즈에는 포함하지 않습니다.

10초는 목표이며 모든 화면 작업에서 보장하지 않습니다. **판단 설명 생성**을 끄면 출력 토큰 수를 줄입니다.
미등록 장소 탐색이나 화면 변화가 많은 작업에서는 추가 추론이 필요합니다.
열린 실행 경로가 모든 요청의 성공을 보장하는 것은 아닙니다. 로컬 모델의 판단 능력과 앱이 제공하는 화면 정보에 따라 실패할 수 있습니다.

## 빌드 요구사항
JDK 21, Android SDK 35, NDK 28.2.13676358, CMake 3.22.1, `third_party/llama.cpp`, `third_party/OpenCL-Headers`,
`python scripts/make-opencl-stub.py`(링크용 OpenCL 스텁, APK에는 들어가지 않음), 빌드 시 `PYTHONUTF8=1`.
모델 파일(GGUF)은 APK에 넣지 않고 `Android/data/dev.localphone.agent/files/models/`에 둡니다.
