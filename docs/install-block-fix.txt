Local Phone Agent — 설치 차단 수정 안내

이번에 휴대폰에 옮길 파일: LocalPhoneAgent-install.apk
이 파일 하나만 설치합니다. instrumentation APK는 일반 사용에 필요하지 않습니다.

확인한 원인
사용자가 보내준 화면은 Google Play 프로텍트의 '기기 보호를 위해 앱 차단됨' 안내입니다.
문구가 Google의 '민감 권한을 선언한 인터넷 사이드로드 앱 차단' 유형과 일치합니다.
기존 APK에는 음악 MediaSession 접근을 위한 알림 listener 서비스가 선언되어 있었습니다.
SMS·Accessibility 접근은 선언하지 않았지만 알림 접근 자체가 해당 차단 기준에 들어갑니다.
이는 실제 악성 동작을 발견했다는 판정과 구분해야 하며 Google의 공식 안내에 따라 권한을 최소화했습니다.
근거: https://developers.google.com/android/play-protect/warning-dev-guidance?hl=en

새 설치판
알림 listener의 Manifest 선언과 서비스 구현을 설치판에서 제외했습니다.
알림 접근 설정을 요청하지 않으며 음악 미디어 제어를 지원하지 않는다고 안내합니다.
음악이 포함된 복합 요청도 전체를 실행 전에 차단하여 지도만 임의로 실행하지 않습니다.
마이크 자동 시작·로컬 한국어 STT·앱 열기·알람·타이머·설정 화면·내비 도구는 유지했습니다.
설치판은 debuggable/testOnly가 아니며 이전 개발판과 같은 인증서로 서명했습니다.
기존 개발판의 음악 코드는 별도 media source set으로 유지하며 설치판에 그 listener 클래스가 포함되지 않습니다.

설치 순서
1. LocalPhoneAgent-install.apk를 휴대폰으로 복사합니다.
2. 삼성 '내 파일'에서 해당 APK를 열어 설치합니다. 별도 XAPK 프로그램은 필요하지 않습니다.
3. 첫 실행에서 마이크 권한을 허용하고 준비 진동 후 '시계 앱 열어줘'로 확인합니다.
4. 보안폴더에서 쓸 때는 보안폴더 → 앱 추가로 Agent와 대상 앱을 추가하고 그 안에서 권한을 따로 허용합니다.
Google Play 프로텍트는 켜 둔 상태로 새 APK를 검사·설치합니다.

검증 범위
새 설치판 APK를 Android 15 전용 AVD에 실제 설치했습니다.
Android 20개 + core JVM 57개 = 이 설치판 기준 고유 77개 PASS. 실패/건너뜀 0.
실제 설치된 패키지의 민감 권한·서비스·클래스 부재와 미지원 음악의 실행 차단을 확인했습니다.
자동 듣기→시계 호출→호출 창 종료, 기존 음성 8개, 시계/설정 7개, Room/Keystore 2개도 검사했습니다.
비행기 모드에서 합성 한국어 WAV를 실제 로컬 STT로 인식해 시계에 7시 알람 요청을 전달했습니다.
서명·ZIP CRC·16 KiB 패키지 정렬도 확인했습니다.
이는 가상폰/패키지 검증이며 실제 S25 Google Play 프로텍트의 승인 결과는 사용자의 재시도로 확인해야 합니다.
이전 개발판의 99개 검사와 새 설치판의 77개는 별도 버전의 결과이며 중복 합산하지 않습니다.
실제 S25 보안폴더·RegiStar·차량 Bluetooth 및 FunctionGemma 모델 추론은 여전히 미검증입니다.
현재 기본 명령 해석은 규칙 기반 테스트 모드입니다.
