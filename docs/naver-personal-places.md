# 네이버 개인 장소 영역 탐색

`집으로 가자`와 `회사로 가자`에서 로컬 장소가 없으면 네이버지도 안의 집/회사 전용 등록을 먼저 탐색합니다. MY 또는 즐겨찾기 안의 **집/회사**, **자주 가는 곳**, 일반 저장 장소를 서로 다른 영역으로 취급하고 관측한 탭을 전환합니다. 다른 목적지도 공식 API/Intent 경로가 해결하지 못하면 자주 가는 곳 등 개인 영역을 확인한 뒤 검색으로 이어갑니다.

영역 이름은 빠른 탐색용 힌트입니다. 실제 화면의 클릭 가능한 부모를 찾아 조작하며 등록하지 않은 집/회사 항목의 등록·추가 버튼을 목적지로 취급하지 않습니다. 세로 장소 목록과 가로 카테고리 탭의 스크롤을 구분합니다. 저장 목록에 없는 장소도 다른 개인 영역과 검색을 시도하므로 장소 사전 등록을 요구하지 않습니다. 오래된 캐시의 장소를 현재 검색에서 찾지 못하면 개인 영역을 다시 탐색합니다. 실제 이름 충돌이나 개인 회사인지 모호한 공개 검색 결과에서만 선택을 요청합니다.

목적지 선택만으로 성공하지 않고 실제 안내 상태를 관측한 뒤에만 선택적 장소 캐시를 기록합니다. 접근성 권한은 사용자 동의가 필요하며 다른 설치 공간의 장소를 읽지 않습니다.

2026-10-08 S25 일반 영역의 실제 네이버지도 접근성 트리에서 집/회사·자주 가는 곳 탭 및 집·회사 행 구조를 확인했습니다. 개인 장소의 이름·주소는 개발 로그에서 제거하고 Git 소스·테스트에는 합성 장소만 씁니다. 자동 테스트는 실제 OS AccessibilityService로 별도의 testOnly 지도 앱을 조작하며 실제 네이버 안내 시작이나 Knox 테스트로 간주하지 않습니다.

공식 안내: [네이버 집/회사, 자주가는 곳](https://help.naver.com/service/5637/contents/703), [네이버 저장 기능](https://help.naver.com/service/5637/contents/692?osType=COMMONOS).
