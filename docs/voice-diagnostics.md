# 중앙·자동 음성 호출 비교 기록 (0.7.3)

설정 → **음성 호출 기록 · 비교** → **비교 기록 시작**을 누른다. 중앙 버튼으로 `회사로 안내해 줘`를 말하고, 뒷면 두 번 두드리기로 같은 문장을 말한 뒤 기록 화면으로 돌아온다. **새로고침 → 비교 결과 복사**로 두 호출과 차이 목록을 함께 복사한다. 긴 기록은 **기록 JSON 저장**으로 사용자가 선택한 위치에 저장한다. 과거 기록을 지우지 않고 새 비교 그룹을 만들며 그 그룹 안에서 같은 원본 문장의 중앙·자동 호출을 짝짓는다. 원본 문장이 다르면 DIFFERENT_TRANSCRIPTS로 표시한다.

각 호출에 UUID, 앱 버전·프로필·PID·선택 모델·설정 snapshot을 붙인다. 중앙 음성의 실패·재질문·취소도 기록한다. 실제 ASR 요청 extras와 순서가 보존된 bias 문자열, native Bundle의 confidence key 존재 여부와 원본 점수 배열, 모든 보관된 N-best·partial·callback 순서와 수신 당시 owner state/token을 남긴다. 마이크 준비·발화 시작/종료·포커스·Activity 상태, engine 생성 시와 음성 준비 시 전경 앱, 실제 resolver 입력/출력·evidence, 화면 선택과 음성 재질문, 모델 준비·system/user/tools·출력·규칙 fallback·policy·실행 결과를 같은 시간축에서 확인할 수 있다. 초 단위 진행 표시나 마이크 RMS callback마다 디스크를 쓰지는 않는다.

종료 전 checkpoint는 IN_PROGRESS이며 완성된 결과와 구분된다. 취소 후 늦은 final도 같은 ID의 이벤트로 남기고 명령을 실행하지 않는다. 모델을 호출하지 않은 기록에 앞선 호출의 모델 응답을 붙이지 않으며, 텍스트 기록에 다른 호출의 ASR 진단을 붙이지 않는다. 원본 점수 0, 점수 미제공, native 원본 배열과 앱에서 해석한 값은 구별된다.

이력은 기존 Android Keystore 암호화 설정 안에 최대 30건·전체 약 2 MiB로 제한한다. 한 호출의 상세 이벤트는 최대 192개·payload 합계 약 384 KiB이며 초과·잘림을 표시한다. 로그 쓰기/암호화/디스크 commit은 전용 worker에서 한다. 상세 기록을 켜지 않으면 명령·모델/화면 내용은 영속 이력에서 제외한다. 상세 기록을 끄면 이후 호출에 적용하며, 기존 이력은 **기록 지우기**로 삭제한다. 음성 파일을 저장하거나 로그를 자동 업로드하지 않는다. 복사와 JSON 저장은 사용자 동작이다.

차이 목록은 원인 확정이 아니다. 첫 원본 문장·confidence·context·bias·판정 결과를 비교하고, 해당 ID의 callback/state 이벤트로 어떤 분기가 실행됐는지 확인한다. 비교 결과에 포함된 입력이 충분해야 추정과 확인을 구분할 수 있다. Android의 일반 앱 실행 정보만으로 런처 호출과 RegiStar의 실제 뒷면 센서 호출을 확정할 수 없어 자동 경로의 origin은 ANDROID_APP_LAUNCH로 유지한다.

0.7.1에서 보고된 뒷면 호출이 confidence 0.0으로 AI 전에 거절된 사실과, 중앙에서 성공했을 때 실제 입력이 무엇이었는지는 별개의 증거다. 새 로그는 앞으로 두 경로를 같은 조건에서 비교하기 위한 기능이다. 과거에 저장하지 않은 중앙 성공의 원본 값을 복원하지 않는다. 기존 10초 성능 목표의 미달 상태는 남아 있으며, 이벤트와 모델 계산 시간으로 이후 지연을 구분한다.
